# 구매·당첨 통계

[`records/STATS.md`](../records/STATS.md)는 `records/`의 CSV로 자동 생성한다. 평일 구매 기록 커밋과 토요일 당첨 확인 커밋 때마다 다시 만든다.

```bash
python3 -m monitor stats                 # records/STATS.md 생성, 누적 요약 출력
python3 -m monitor stats --output /tmp/stats.md
```

| 구역 | 내용 |
| --- | --- |
| 요약 | 구매 게임·금액, 당첨 확인·추첨 전 게임, 당첨 게임·금액, 손익, 회수율 |
| 등수별 당첨 | 1~5등 횟수 |
| 일치 개수 분포 | 게임별 일치 개수 0~6 |
| 회차별 | 회차, 추첨일, 게임, 구매액, 당첨 게임, 당첨금 |
| 월별 | 구매월 기준 게임·구매액, 추첨월 기준 당첨금 |
| 번호 | 내가 받은 번호 빈도, 받지 않은 번호, 확인한 회차의 당첨번호 빈도, 구매 방식 |

손익과 회수율은 당첨 확인이 끝난 게임만 계산한다. 추첨 전 게임은 손실로 세지 않는다. 당첨금은 회차별 1인당 당첨금이며 세금 공제 전이다.

토요일 당첨 결과 Discord 메시지에는 누적 요약 한 줄(`📊 누적 …`)을 덧붙인다.

공개 저장소이므로 계정 잔액은 통계와 기록에 넣지 않는다. 잔액은 토요일 잔액 알림의 Discord 메시지로만 확인한다. 원본 CSV는 내려받아 스프레드시트 등에서 직접 분석할 수 있다.

## 과거 이력

`records/history.csv`는 동행복권 마이페이지에서 내보낸 구매내역(`동행복권_구매이력_전체.xlsx`, 2015-04-03 ~ 2026-09-19, 357건)을 2026년 11월 1일 변환한 것이다. 열은 구입일, 복권 종류, 회차, 매수, 당첨 결과, 당첨금, 추첨일이다. 표 번호(바코드)와 주문번호는 공개 저장소에 올리지 않았다.

통계에는 두 구역이 추가된다.

- 전체 기간 로또6/45: 과거 이력과 자동구매 기록(추첨이 끝난 게임)을 합친 구매액·당첨금·손익·회수율.
- 과거 이력: 복권 종류별 합계와 로또6/45 연도별 표, 로또 등수별 당첨 횟수(5,000원은 5등, 50,000원은 4등).

로또6/45와 연금복권은 1매 1,000원으로 계산했다. 캐치미·트레져헌터·트리플럭·파워볼은 내보낸 파일에 가격이 없어 구매액을 비워 둔다. 구매내역의 당첨 건수는 구매 건(최대 5게임) 단위다.

과거 이력(~09-19)과 자동구매 기록(10-09~) 사이에 다른 방법으로 산 표(예: `vibe-lotto`의 09-26, 10-03 구매)는 포함되지 않는다. 구매내역을 다시 내보내면 같은 방식으로 `history.csv`를 교체할 수 있다.
